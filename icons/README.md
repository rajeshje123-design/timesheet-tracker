# App Icons

You need to provide two PNG icons for the PWA:
- icon-192.png (192x192 pixels) — used by Android
- icon-512.png (512x512 pixels) — used for splash screens

Design tip: Use a clock/timer icon on an indigo (#6366f1) background.
You can generate these at: https://favicon.io/ or https://realfavicongenerator.net/
